# Classificação da Qualidade do Sono com Base no Uso Excessivo de Smartphones Utilizando Weka

## Descrição
Projeto acadêmico da disciplina de Inteligência Artificial utilizando aprendizado de máquina no Weka para classificar a qualidade do sono com base em hábitos de uso de smartphones.

## Objetivo
Investigar padrões entre uso excessivo de smartphones e qualidade do sono utilizando técnicas de classificação supervisionada.
